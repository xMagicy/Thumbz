Blok E — Hybrid category classifier (KRITIEK)
Doel: 100% accurate UI category mapping. Geen gaming in Vlog, geen lyric video in Music, etc.

Aanpak: hybrid classifier per thumbnail. Volgorde van evaluatie matters — meest specifieke eerst, broad catch-all laatste. Eerste match wint.

Sla resultaat op in app_category (text). Sla bij meervoudige match een category_confidence (low/medium/high) op voor monitoring.

Evaluation order
Gaming → 2. Music → 3. Finance → 4. Tech → 5. Tutorial → 6. Lifestyle → 7. Vlog → 8. Other (catchall)

Confidence scoring
Voor monitoring/debugging:

High: matched on categoryId + minstens 1 keyword/channel pattern
Medium: matched alleen op keyword (geen categoryId match)
Low: matched op channel pattern alleen, of in catchall (Other)
Logging: bij elke sync log totaal aantal per category + per confidence level. Voorbeeld console output:

Gaming:    245 (high: 180, medium: 60, low: 5)

Als Other > 30% van pool → keyword regels te strict, breid uit.
