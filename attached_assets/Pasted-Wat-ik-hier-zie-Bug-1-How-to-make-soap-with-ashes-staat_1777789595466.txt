Bug 2: "Champions" met 0 battles

Bug 2: Champions vereist minimum battles
Filter Champions ranking op battle_count >= 5. Thumbnails met minder dan 5 battles zijn niet "champions" — het zijn newcomers met default ELO.

Pas aan in de query voor /api/thumbnails?sort=rating:

WHERE archived = false 
  AND status = 'active'
  AND battle_count >= 5
ORDER BY elo_rating DESC
Voor de "Top Contenders / Climbing fast" sectie: gebruik battle_count >= 3 (lagere drempel, want hier wil je juist newcomers tonen).

Bug 3: "Shorts" in channel name blacklisten
Voeg "Shorts" toe aan CHANNEL_BLOCKLIST_TERMS met word-boundary match:

// In de channel name check:
